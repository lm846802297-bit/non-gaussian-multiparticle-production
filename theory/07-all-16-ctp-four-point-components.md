# All 16 CTP Components of the Connected Four-Point Function

Status: selected finite-volume spacetime configurations evaluated; all 16 contour-branch assignments computed. This is not a full continuous spacetime grid or a continuum-limit result.

## 1. Model and conventions

We use the regulated 1+1D real scalar theory

\[
\mathcal L=\frac12(\partial\phi)^2-\frac12m^2\phi^2
-\frac{\lambda(t)}{4!}:\!\phi^4\!:\,_m,
\qquad
\lambda(t)=\lambda_0\operatorname{sech}^2(t/T),
\]

with periodic spatial length \(L\), momentum modes \(p_n=2\pi n/L\), and normal ordering relative to the free mass-\(m\) vacuum with the same mode regulator. The initial state is the free Gaussian vacuum at \(t_0=-12T\). The final reference time is \(t_f=+12T\), where the pulse is exponentially small.

We use contour correlators without an additional factor of \(-i\):

\[
F_4^{a_1a_2a_3a_4}(1,2,3,4)
=\langle T_C\phi_{a_1}(1)\phi_{a_2}(2)\phi_{a_3}(3)\phi_{a_4}(4)\rangle,
\]

where each \(a_i\in\{+,-\}\). The connected component is

\[
\begin{aligned}
F_{4,c}^{a_1a_2a_3a_4}={}&F_4^{a_1a_2a_3a_4}
-F_2^{a_1a_2}(1,2)F_2^{a_3a_4}(3,4)\\
&-F_2^{a_1a_3}(1,3)F_2^{a_2a_4}(2,4)
-F_2^{a_1a_4}(1,4)F_2^{a_2a_3}(2,3).
\end{aligned}
\]

## 2. Branch-state construction

The key implementation improvement is to calculate the two contour branches as two forward-evolved Schrödinger states and combine them by an overlap.

For a subset \(S\subseteq\{1,2,3,4\}\), let its events be sorted in increasing physical time, \(t_{i_1}\le\cdots\le t_{i_r}\). Define

\[
\begin{aligned}
|\chi_S\rangle={}&U(t_f,t_{i_r})\Phi(x_{i_r})
U(t_{i_r},t_{i_{r-1}})\cdots\\
&\times\Phi(x_{i_1})U(t_{i_1},t_0)|0_{\rm in}\rangle,
\end{aligned}
\]

with \(|\chi_\varnothing\rangle=U(t_f,t_0)|0_{\rm in}\rangle\). Here \(U(t_2,t_1)\) is the exact finite-dimensional propagator generated by the projected Hamiltonian \(H(t)=H_0+\lambda(t)V\), and \(\Phi(x)\) is the regulated equal-time field operator.

Given a branch assignment \(a_1a_2a_3a_4\), define

\[
S_+=\{i:a_i=+\},\qquad S_-=\{i:a_i=-\}.
\]

Then the contour component is

\[
\boxed{
F_4^{a_1a_2a_3a_4}(1,2,3,4)
=\langle\chi_{S_-}|\chi_{S_+}\rangle.
}
\]

The ket on the forward branch inserts its fields in chronological order. Taking its adjoint produces the anti-time-ordered insertions on the backward branch. This construction evaluates all 16 branch assignments from 16 cached subset states. Each branch-resolved two-point function in the connected subtraction is obtained from the corresponding pair of subset states.

This is a direct closed-time-path construction, not an assumption that all components can be inferred from the all-forward component.

## 3. CTP identities used as checks

For Hermitian fields, complementing every branch assignment gives

\[
F_{4,c}^{\bar a_1\bar a_2\bar a_3\bar a_4}
=\left(F_{4,c}^{a_1a_2a_3a_4}\right)^*.
\]

For the latest physical-time event, the largest-time identity requires the correlator to be unchanged when only that event's branch label is flipped. In our input ordering, event 1 is the latest-time event, so

\[
F_{4,c}^{+a_2a_3a_4}=F_{4,c}^{-a_2a_3a_4}.
\]

At equal physical times, the scalar fields commute at equal time, so all 16 contour components coincide (up to finite-basis numerical errors).

## 6. Validation results

Across all four configurations and all 16 branch assignments:

- Maximum relative change from \(N_{\max}=12\) to 16: \(4.60\times10^{-12}\).
- Maximum complement-conjugation residual: zero at stored floating-point precision (the two overlaps are evaluated as conjugate pairs).
- Maximum largest-time identity residual: \(4.62\times10^{-17}\) absolute.
- Six automated tests pass, including all-16 coverage, complement conjugation, largest-time branch independence, equal-time branch independence, free-vacuum connected cancellation, and interaction-generated connected signal.
- The all-forward `++++` values for configurations A and B agree with the earlier independently implemented time-ordered correlator code to relative differences below \(4.31\times10^{-13}\).

The interaction matrix Hermiticity residual is \(2.22\times10^{-16}\) in the Nmax=16 runs.

## 7. Interpretation and limitations

The calculation establishes all 16 contour components for four selected spacetime configurations and a three-point spatial-separation scan at fixed unequal times. It does not yet provide a dense four-coordinate spacetime grid, all possible event-time orderings, a momentum-mode cutoff extrapolation, or a continuum/infinite-volume result. The retained momentum cutoff is \(K_{\rm cut}=1\), so the results are a finite-mode benchmark.

The next theoretical step is to use these branch-resolved components to test the exact connected four-point Schwinger-Dyson equation numerically and then quantify the six-field composite term that drives the four-point hierarchy. A controlled 2PI/Bethe-Salpeter or 4PI closure must be compared against the finite-Hilbert benchmark rather than assumed.

No final novelty claim is made.
